# Code of Conduct

## Our Standards

Interactions in this repository's issue tracker should be respectful and
constructive. Expected behaviour includes:

- Using welcoming and inclusive language
- Focusing on what is best for the project
- Accepting feedback gracefully
- Showing empathy toward other community members

Unacceptable behaviour includes:

- Harassment, trolling, or insulting comments
- Personal or political attacks
- Publishing others' private information without permission
- Any conduct that would reasonably be considered inappropriate in a
  professional setting

## Scope

This Code of Conduct applies to all activity within this repository, including
issues and any other communication associated with the project.

## Enforcement

Issues that violate this Code of Conduct will be closed and the user may be
blocked from the repository at the maintainer's discretion.

To report a conduct issue privately, use GitHub's security advisory feature:
https://github.com/erinversfeldcodes/thestacks/security/advisories/new

Do not report conduct issues through public GitHub issues.
