# US-15.6.3 — Read What the Platform Measures About You

## 1. User Story

> **As a** reader who has been told the platform is transparent, **I want to** read what it actually measures and why **so that** the claim is something I can check rather than something I have to believe.

**What the reader wants:** to know what is collected about them, what deliberately is not, and
the reasoning — not a privacy policy written to be unreadable.

**What they get:** the essay explaining the measurement philosophy, paired with the metrics surface
that shows the numbers. The essay is the *why*; the metrics page is the *what*.

**Acceptance criteria:**
- Reads as finished prose to a signed-out visitor.
- Reachable from the metrics surface, which is where a reader looking at numbers will want it.
- No editorial scaffolding visible to the public.

## 2. UI Interaction Flow

### Happy path
1. The reader opens `/transparency` — directly, or from a link on another public page.
2. The page renders.

### Sad paths
- **Content fails to load** (where the page fetches): a failure state that reads as a failure, not
  as an empty or zero-valued page.

## 3. API Calls

None — the SPA renders this route from static content.

## 4. Auth & Middleware Guards

Public. No authentication, no visibility resolution, no age gate. This page is written to be read
by someone who has not signed up and may never — gating it would defeat its purpose.

## 5–11. Database, Events, Jobs, External Services, Storage, Cache, dbt

**None.** The essay describes what other parts of the system record; it records nothing itself.

## 12. Elm Frontend State Machine (Detail)

- **Route**: `Route.DataTransparency` — `/transparency`, public pipeline.
- **Init**: no fetch — static prose.
- **View**: `Page.DataTransparency`; essay sections with onward links to `/costs` and `/metrics`.

## Why this story exists

Written 2026-08-20. This route shipped and was **live to the public with no user story** — one of
four such routes found by the campaign's story census. A public page with no story is a page whose
purpose is recorded nowhere: nothing states who it is for or what it must not do, so nothing can
notice when it drifts from either.
