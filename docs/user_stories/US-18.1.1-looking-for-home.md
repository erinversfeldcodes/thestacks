# US-18.1.1 — Browse the Looking for a Home Shelf

## 1. User Story

> **As a** user, **I want to** browse my "Looking for a Home" shelf **so that** I can see all the books I have listed or intend to list for second-hand sale, displayed as books ready to find a new reader.

**Acceptance criteria:**
- The Looking for a Home shelf is accessible via `/looking-for-home`
- The page renders books placed on this shelf with the appropriate aesthetic
- The shelf appears in the navigation bar between Reading Pile and the Catalogue dropdown
- The shelf supports the same interactions as other bookshelves (click spine to view detail, move between shelves)
- The empty state displays an encouraging message about finding books new homes
- Swipe navigation includes this shelf in the bookshelf sequence

---

## 2. UI Interaction Flow

### Happy Path
1. User clicks "Looking for a Home" in the top navigation.
2. Route resolves to `Route.LookingForHome` (`/looking-for-home`).
3. `initPageAuthenticated` creates `PageLookingForHome` and calls `LookingForHome.init maybeToken`.
4. `init` fires `Api.getBookshelf "looking_for_home" token BooksLoaded`.
5. While loading: "Loading your books looking for a home..." message.
6. On success with books: Renders a `div.pile-view` with cover cards for each placement.
7. On success with no books: Renders `emptyBookshelf` component with message: "Nothing here yet — these are books looking for a new home."

### Age Gate
If the API returns 403 (age-gated content), the age gate overlay renders with options to verify age or dismiss.

### Sad Paths
- **API error**: "Could not load your books looking for a home. Please try again."
- **Age gate**: `showAgeGate = True`, renders `AgeGate` component with "Verify Age" and "Dismiss" buttons.

### Elm State Machine
- **Page module**: `Page.Bookshelf.LookingForHome`
- **Model fields**: `books : RemoteData Http.Error (List Placement)`, `showAgeGate : Bool`
- **Msg flow**: `BooksLoaded (Ok placements)` -> `books = Success placements`; `BooksLoaded (Err (Http.BadStatus 403))` -> `showAgeGate = True`; `VerifyAge` -> navigate to age verification; `DismissAgeGate` -> hide gate.
- **OutMsg pattern**: `NavigateTo Route` — used for age verification redirect and book detail overlay.

---

## 3. API Calls

### `GET /api/bookshelves/looking_for_home`
- **Auth**: Required (Bearer JWT)
- **Pipeline**: `:api`, `:authenticated`, `:view_as`
- **Controller**: `StacksWeb.BookshelfController.show/2`
- **Response (success)**: JSON array of placements with book data — HTTP 200
- **Response (error)**: HTTP 403 (age-gated), HTTP 401 (unauthenticated)
- **Context function**: `Shelving.get_bookshelf_books/2` — queries `op.bookshelf_placements` joined with `op.bookshelves` where `name = "looking_for_home"`, filtered to non-removed placements.

## 4. Auth & Middleware Guards

- **Plugs fired**: `SecurityHeaders` -> `AuthPipeline` -> `ViewAsPlug`
- **ViewAsPlug**: Supports `?view_as=<perspective>` query param for preview of how the shelf looks to different audiences.
- **Visibility checks**: Bookshelf visibility is checked by the controller.

## 5. Database Interactions

### Read: Load placements
- **Table(s)**: `op.bookshelf_placements` joined with `op.bookshelves` and `op.books`
- **Query**: Placements where `bookshelf.name == "looking_for_home"` and `bookshelf.user_id == current_user.id` and `removed_at IS NULL`.
- **Preloads**: Book data (title, author, page count, editions, subjects)
- **Schema modules**: `Stacks.Shelving.Placement`, `Stacks.Shelving.Bookshelf`

## 12. Elm Frontend State Machine (Detail)

### Route
- **Route variant**: `Route.LookingForHome`
- **URL**: `/looking-for-home`
- **Public or authenticated**: Authenticated only
- **Browser tab title**: "Looking for a Home — The Stacks"

### Init
- **`LookingForHome.init maybeToken`**: Sets `books = Loading`, fires `Api.getBookshelf "looking_for_home" token BooksLoaded`.
- **Initial model**: `{ books = Loading, showAgeGate = False }`

### Update cycle
- **Msg**: `BooksLoaded (Ok placements)` -> `books = Success placements`
- **Msg**: `BooksLoaded (Err (Http.BadStatus 403))` -> `books = Failure`, `showAgeGate = True`
- **Msg**: `BooksLoaded (Err err)` -> `books = Failure err`
- **Msg**: `VerifyAge` -> OutMsg `NavigateTo SettingsAgeVerification`
- **Msg**: `DismissAgeGate` -> `showAgeGate = False`
- **Main.elm handling**: `LookingForHomeMsg` delegates to `LookingForHome.update`. `NavigateTo (Route.BookDetail bookId)` opens overlay; other `NavigateTo` routes use `Nav.pushUrl`.

### View
- `div.page.page--bookshelf.shelf-looking-for-home`
- `h1.page__title` — "Looking for a Home"
- Age gate: `ageGate { onVerify, onDismiss }` component
- Loading: `div.loading` with text
- Error: `p.error` with contextual message
- Empty: `emptyBookshelf` component with encouraging message
- Books: `div.pile-view` with `div.pile-view__book` cards, each showing:
  - `div.pile-view__cover` with title and author
- **Swipe navigation**: Included in `SwipeNavigation.bookshelfRoutes` as the 5th (last) shelf.
- **CSS classes**: `page--bookshelf`, `shelf-looking-for-home`, `pile-view`, `pile-view__book`, `pile-view__cover`, `pile-view__title`, `pile-view__author`, `loading`, `error`

## 13. Operational Metrics

- **Page load rate**: Count of `GET /api/bookshelves/looking_for_home` requests per day.
- **API success rate**: Ratio of HTTP 200 responses to total requests.
- **API failure rate by type**: Breakdown — HTTP 401 (unauthenticated), HTTP 403 (age-gated).
- **Age gate trigger rate**: Percentage of page loads that result in 403 and trigger the age gate overlay.
- **Age gate resolution**: Ratio of "Verify Age" clicks to "Dismiss" clicks on the age gate.
- **Empty shelf rate**: Percentage of successful loads that return zero placements. High rates indicate users are not using this bookshelf.
- **Placement count distribution**: Average and median number of books on the Looking for a Home shelf.

---

## 14. Performance & Usability Metrics

- **Page load time**: p50/p95 for `GET /api/bookshelves/looking_for_home` including DB query (join across `bookshelf_placements`, `bookshelves`, `books`). Should be <300ms.
- **Time-to-first-paint**: Time from navigation to visible content (loading message, then books). Includes API round-trip.
- **Book interaction rate**: Percentage of page loads where the user clicks a book to open the detail overlay.
- **Swipe-to/from rate**: How often users arrive at or leave this shelf via swipe navigation (it is the 5th/last in the swipe sequence).
- **Empty state engagement**: When the shelf is empty, do users navigate to upload or another shelf? Track next-action after seeing the empty state.
- **Marketplace conversion**: Percentage of books on this shelf that are subsequently listed on the marketplace (downstream metric).

---

## 15. Cost Tracking

- **Database reads**: One query joining `op.bookshelf_placements`, `op.bookshelves`, and `op.books` per page load. Includes preloads for book data. Negligible Neon cost for typical collection sizes (<1000 books).
- **No external service calls**: Browsing the shelf does not call Resend, vision, or any external APIs.
- **Fly.io compute**: One request handler invocation per page load. Negligible.
- **ViewAsPlug overhead**: If `?view_as=` is present, additional visibility checks are performed. Minimal additional cost.
- **Total per-page-load cost**: ~$0.00 (one DB read, no external services).
