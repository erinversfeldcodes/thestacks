# US-12.3.1 — Every LLM Path Has a Budget Ceiling

## 1. User Story

> **As the** platform owner, **I want** every path that spends money on a model call to stop at
> a recorded ceiling **so that** a bug, a loop, or a popular day cannot turn into a surprise
> bill.

**Status: partially built; the gap is recorded.** `BudgetTracker` guards the Modal path; the
Together path (book associations) has a circuit fuse but NO budget — a fuse protects against a
failing provider, not against a succeeding one called too often.

**Acceptance criteria:**
- Each provider path names its ceiling and its behaviour at the ceiling (refuse new work,
  never corrupt in-flight work).
- The ceiling's enforcement has a test that can fail (the mocked-guard lesson: a budget mocked
  away is a budget that does not exist).
- Spend against ceiling is visible on the ops dashboard from billed/metered truth
  (US-1.1.13).

## 2. Validation (for the Together gap, when closed)

- A planted over-budget call refused, with the refusal's telemetry asserted at the scrape.
