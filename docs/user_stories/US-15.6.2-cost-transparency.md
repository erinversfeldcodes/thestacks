# US-15.6.2 — See What the Platform Costs to Run

## 1. User Story

> **As a** reader deciding whether to trust a service that costs me nothing, **I want to** see what it actually costs its owner **so that** I can judge how it is paid for and what that implies.

**What the reader wants:** the honest answer to "if I am not paying, who is, and what do they
want in return".

**What they get:** the current period's costs itemised per provider — compute, database, email,
metadata APIs, search — with what each line counts and, where it matters, what it does **not**
count.

**Acceptance criteria:**
- Every third-party the platform integrates with appears, free tier or not.
- A line that estimates rather than measures says so.
- A line that omits part of its cost says what it omits. (The Modal line counts inference only;
  a container also bills while idle for up to its scaledown window, and the description says so.)
- Loading and failure states are distinguishable from "the costs are zero".

## 2. UI Interaction Flow

### Happy path
1. The reader opens `/costs` — directly, or from a link on another public page.
2. The page renders.

### Sad paths
- **Content fails to load** (where the page fetches): a failure state that reads as a failure, not
  as an empty or zero-valued page.

## 3. API Calls

`GET /api/costs` — public, no auth. Controller: `StacksWeb.CostController`.

## 4. Auth & Middleware Guards

Public. No authentication, no visibility resolution, no age gate. This page is written to be read
by someone who has not signed up and may never — gating it would defeat its purpose.

## 5–11. Database, Events, Jobs, External Services, Storage, Cache, dbt

**None.** Reads the current period's cost items via the controller; the page itself owns no schema. `Stacks.Workers.RefreshCostsJob` recomputes them from live usage counts.

## 12. Elm Frontend State Machine (Detail)

- **Route**: `Route.CostTransparency` — `/costs`, public pipeline.
- **Init**: `GET /api/costs` -> `StacksWeb.CostController`; `RemoteData` Loading → Success/Failure.
- **View**: `Page.CostTransparency`; a line item per provider with its description.

## Why this story exists

Written 2026-08-20. This route shipped and was **live to the public with no user story** — one of
four such routes found by the campaign's story census. A public page with no story is a page whose
purpose is recorded nowhere: nothing states who it is for or what it must not do, so nothing can
notice when it drifts from either.
