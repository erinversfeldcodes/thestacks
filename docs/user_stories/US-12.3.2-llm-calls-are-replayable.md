# US-12.3.2 — Every LLM Call Is Logged, Scored, Replayable

## 1. User Story

> **As the** platform owner improving model behaviour, **I want** every LLM call recorded with
> its inputs, outputs and a quality score **so that** "did that prompt change help?" is a query,
> not a feeling.

**Status: future-spec** (recorded from the absence pass; counters exist, no call log or replay).

**Acceptance criteria (when built):**
- Per call: prompt identity (versioned), inputs' provenance, output, latency, cost, and any
  score — in a Langfuse-compatible shape so tooling is optional, not bespoke.
- GDPR first-class: author-derived content in logs follows the same erasure/export reach as
  its sources; retention is a recorded decision.
- Replay drives the SAME seam production uses (the eval-harness lesson).

## 2. Validation (when built)

- One recorded call replayed byte-identically; erasure reaches a planted log row.
