# US-12.3.5 — "What Should I Read Next?"

## 1. User Story

> **As a** reader staring at my own shelves, **I want** suggestions grounded in what I own and
> what I wrote about it **so that** the next book comes from my library's shape, not a
> popularity chart.

**Status: Phase-2 spec, under consideration** (recorded; mapping lists it as such). The
substrate now exists: `op.embeddings` + the shared pgvector serving story
(`docs/vision-embedding-substrate.md`), and the small-catalogue regime is exactly where
embeddings measurably win.

**Acceptance criteria (when taken up):**
- Recommendations draw only on the reader's own data per consent (ADR 017 machinery).
- Grounded presentation: each suggestion says WHY (which shelf, which post, which neighbours).
- Offline recall-style eval before any UI ships (the corpus-first discipline).
