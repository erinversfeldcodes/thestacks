# US-12.2.1 — Use the Writing Assistant

## 1. User Story

> **As a** user, **I want** a Socratic writing assistant embedded in the blog editor **so that** I can refine my arguments, surface blind spots, and deepen my thinking by drawing on my reading history.

The writing assistant lives as a collapsible side panel in the blog editor. It operates in two modes:

- **Promptable** — the user opens the panel and asks directly ("I'm not feeling strong about this argument")
- **Proactive** — after a save or ~90 seconds of writing inactivity, a quiet pulsing dot on the assistant icon signals that something is worth thinking about

The assistant knows what the user has read (library), what they intend to read (wishlist, antilibrary), what they have written before (past posts), and the content of public domain books on their shelves. It asks questions. It does not write for the user.

**Acceptance criteria:**
- [ ] Assistant panel renders in the blog editor, collapsed by default
- [ ] Proactive nudge dot appears after save (debounced, max once per 10 minutes)
- [ ] Prompted dialogue returns a Socratic response within the panel
- [ ] Five conversation modes available: Clarify, Strengthen, Challenge, Expand, Synthesise
- [ ] Bot turns never lead with praise; compression prompt used for weak arguments
- [ ] All cited books exist on the user's shelves — no invented titles
- [ ] Thumbs down available on bot turns (hover, no thumbs up)
- [ ] "Not relevant" dismiss available on proactive nudges
- [ ] Unresolved observation at publish time triggers non-blocking "publish anyway?" prompt
- [ ] Panel does not render if `consent_writing_assistant` is false
- [ ] Crisis content in output replaced with static human-written resource message

## 2. UI Interaction Flow

### Happy Path — Proactive Nudge
1. User is editing a post in `/blog/posts/:id/edit`.
2. User clicks "Save Draft".
3. `blog.post_updated` event fires -> `WritingAssistantNudgeHandler` (debounced) -> `WritingAssistantNudgeWorker` enqueued.
4. Worker generates a single observation and stores it in `op.blog_assistant_sessions`.
5. Elm receives the nudge via SSE on `GET /api/blog/posts/:id/assistant/nudge`.
6. A small pulsing dot appears on the assistant icon — no interruption to flow.
7. User continues writing. At their own pace they click the assistant icon.
8. Panel opens showing the nudge: a single 1–2 sentence observation.
9. User can dismiss ("Not relevant") or begin a conversation by replying.

### Happy Path — Prompted Dialogue
1. User opens the assistant panel manually.
2. User selects a mode (e.g. "Challenge") from the mode selector.
3. User types a message: "I'm not sure this argument holds up."
4. Elm sends `POST /api/blog/posts/:id/chat` with `{ message, mode, session_id? }`.
5. Response streams via SSE — the bot turn appears progressively in the panel.
6. Bot asks a question rather than giving a verdict.
7. User responds. Conversation accumulates in the session.
8. After sufficient exchange, a "Synthesise" turn generates a structured summary: starting claim, what shifted, what held, remaining gaps.

### Happy Path — Publish with Unresolved Observation
1. User clicks "Publish" with an open unresolved nudge.
2. A non-blocking prompt appears: "There's something unresolved here — publish anyway?"
3. User can proceed or return to the editor.

### Sad Paths
- **Consent not granted**: Panel does not render. Settings link shown instead: "Enable the writing assistant in Privacy & Consent."
- **Assistant service unavailable**: Circuit breaker open — panel shows "The assistant is temporarily unavailable. Your writing is saved." No retry visible to user.
- **Input classified as off-topic**: Bot responds: "That's outside what I'm here for. What's the claim you're testing?"
- **Input classified as harmful**: Input rejected silently with: "I can only help with arguments in your writing or books on your shelves."
- **Crisis content detected in output**: Static human-written message returned pointing to appropriate resources. No generated response.
- **No shelf data**: Bot can still engage but notes: "I don't have any books from your shelves to draw on yet."
- **Ghost-writing attempt**: Output discarded, bot responds: "I can ask questions about your argument. Writing it is your job."
- **SSE connection lost**: Panel shows reconnecting state; session persists in DB so conversation is not lost on reconnect.

### Elm State Machine
- **Page module**: `Page.Blog.Editor` (assistant panel embedded)
- **Model fields involved**:
  - `assistantPanel : AssistantPanel` — `Collapsed | Open | Loading`
  - `nudgeAvailable : Bool`
  - `nudgeDismissed : Bool`
  - `selectedMode : AssistantMode` — `Clarify | Strengthen | Challenge | Expand | Synthesise`
  - `chatInput : String`
  - `session : RemoteData Http.Error AssistantSession`
  - `streamingTurn : Maybe String`
  - `publishGate : PublishGate` — `Clear | UnresolvedNudge`
- **Msg flow**:
  - `NudgeReceived nudge` → sets `nudgeAvailable = True`
  - `OpenAssistantPanel` → sets `assistantPanel = Open`, loads session
  - `CloseAssistantPanel` → sets `assistantPanel = Collapsed`
  - `SelectMode mode` → updates `selectedMode`
  - `SetChatInput str` → updates `chatInput`
  - `SubmitChat` → sends `POST /api/blog/posts/:id/chat`, sets `streamingTurn = Just ""`
  - `StreamChunkReceived chunk` → appends to `streamingTurn`
  - `StreamComplete turn` → appends turn to session, clears `streamingTurn`
  - `DismissNudge` → sends dismiss signal, sets `nudgeDismissed = True`
  - `ThumbsDown turnIndex` → sends `POST /api/blog/posts/:id/chat/feedback`
  - `PublishWithGate` → checks `publishGate`; if `UnresolvedNudge` shows confirmation modal
- **RemoteData states**: `session`: `NotAsked → Loading → Success/Failure`

## 3. API Calls

### `POST /api/blog/posts/:id/chat`
- **Auth**: Required (JWT Bearer token)
- **Pipeline**: `:api`, `:authenticated`, consent gate (`consent_writing_assistant`)
- **Controller**: `StacksWeb.WritingAssistantController.chat/2`
- **Request body**: `{ message: string, mode: "clarify"|"strengthen"|"challenge"|"expand"|"synthesise", session_id?: uuid }`
- **Response (success)**: SSE stream of turn chunks, terminated with `{ turn_id, session_id, role: "assistant" }` — HTTP 200
- **Response (error)**:
  - `{ error: "consent_required" }` — HTTP 403 (consent not granted)
  - `{ error: "out_of_scope" }` — HTTP 422 (input classified off-topic/harmful)
  - `{ error: "service_unavailable" }` — HTTP 503 (circuit breaker open)

### `GET /api/blog/posts/:id/assistant/session`
- **Auth**: Required (JWT Bearer token)
- **Pipeline**: `:api`, `:authenticated`, consent gate
- **Controller**: `StacksWeb.WritingAssistantController.session/2`
- **Response (success)**: `{ session_id, turns: [{ role, content, turn_index, inserted_at }], nudge?: { content, dismissed } }` — HTTP 200
- **Response (error)**: `{ session: null }` — HTTP 200 when no session exists yet (not a 404)

### `POST /api/blog/posts/:id/assistant/nudge/dismiss`
- **Auth**: Required (JWT Bearer token)
- **Pipeline**: `:api`, `:authenticated`
- **Controller**: `StacksWeb.WritingAssistantController.dismiss_nudge/2`
- **Request body**: None
- **Response (success)**: `{ dismissed: true }` — HTTP 200

### `POST /api/blog/posts/:id/chat/feedback`
- **Auth**: Required (JWT Bearer token)
- **Pipeline**: `:api`, `:authenticated`
- **Controller**: `StacksWeb.WritingAssistantController.feedback/2`
- **Request body**: `{ turn_index: integer, signal: "negative_explicit" }`
- **Response (success)**: `{ recorded: true }` — HTTP 200

## 4. Auth & Middleware Guards

- **Plugs fired** (in order): `SecurityHeaders` → `AuthPipeline` (`:authenticated`) → `ConsentGate` (checks `user.consent_writing_assistant`) → controller action
- **Consent gate**: Returns HTTP 403 with `{ error: "consent_required", settings_url: "/settings/consent" }` if `consent_writing_assistant` is false
- **Visibility checks**: Post ownership verified — only the post owner can access the writing assistant for that post
- **Age gate**: N/A
- **Ownership checks**: `WritingAssistantController` verifies `post.user_id == current_user.id` before routing to assistant

## 7. Background Jobs (Oban)

### `Stacks.Workers.WritingAssistantNudgeWorker`
- **Worker**: `Stacks.Workers.WritingAssistantNudgeWorker`
- **Queue**: `:default`
- **Args**: `%{ "post_id" => post_id, "user_id" => user_id }`
- **Max attempts**: 2
- **Uniqueness**: `period: 600, keys: [:post_id]` — enforces debounce at job level
- **What it does**:
  1. Checks `user.consent_writing_assistant` — skips if false
  2. Loads current post body
  3. Loads active `system` prompt template from `op.prompt_templates`
  4. Calls RAG retrieval: hybrid search against user's embeddings for post body
  5. Assembles context: post body + top-15 retrieved chunks + recent session turns
  6. Calls `Stacks.AI.WritingAssistantClient.nudge/3` — generates single observation
  7. Post-generation classification: ghost-writing check, hallucination check, crisis check
  8. Stores result as a new turn (role: `"nudge"`) in `op.blog_assistant_sessions`
  9. Emits `writing_assistant.nudge_generated`
- **On success**: SSE notifies open editor session; `nudgeAvailable` set in Elm
- **On failure**: Circuit breaker `:writing_assistant_fuse` — silent failure, no nudge shown

## 12. Elm Frontend State Machine (Detail)

### Route
- **Route variant**: `Route.BlogEdit String` (assistant panel is embedded, not a separate route)
- **URL**: `/blog/posts/:id/edit`
- **Public or authenticated**: Authenticated

### Init
- **`initPage` branch**: `Page.Blog.Editor.init (Edit postId) maybeToken`
- **API calls on init**: `Api.getBlogPost`, then if post loaded: `Api.getAssistantSession postId`
- **Initial model state**:
  - `assistantPanel = Collapsed`
  - `nudgeAvailable = False`
  - `nudgeDismissed = False`
  - `selectedMode = Clarify`
  - `chatInput = ""`
  - `session = NotAsked`
  - `streamingTurn = Nothing`
  - `publishGate = Clear`

### Update cycle
- **Msg**: `SessionLoaded (Ok session)` → `session = Success session`; if session has undismissed nudge turn → `nudgeAvailable = True`, `publishGate = UnresolvedNudge`
- **Msg**: `NudgeReceived` (from SSE) → `nudgeAvailable = True`, `publishGate = UnresolvedNudge`
- **Msg**: `OpenAssistantPanel` → `assistantPanel = Open`; if `session = NotAsked` fires `Api.getAssistantSession`
- **Msg**: `CloseAssistantPanel` → `assistantPanel = Collapsed`
- **Msg**: `SelectMode mode` → `selectedMode = mode`
- **Msg**: `SetChatInput str` → `chatInput = str`
- **Msg**: `SubmitChat` → clears `chatInput`, sets `streamingTurn = Just ""`, fires `Api.postChat`
- **Msg**: `StreamChunkReceived chunk` → appends to `streamingTurn`
- **Msg**: `StreamComplete turn` → appends turn to `session.turns`, `streamingTurn = Nothing`
- **Msg**: `DismissNudge` → fires `Api.dismissNudge`, sets `nudgeDismissed = True`, `publishGate = Clear`
- **Msg**: `ThumbsDown turnIndex` → fires `Api.postFeedback turnIndex "negative_explicit"`
- **Msg**: `PublishWithGate` → if `publishGate = UnresolvedNudge` shows confirmation modal; if `Clear` proceeds with normal `Publish` msg

### View
- **Assistant icon**: Small icon in editor toolbar; pulsing dot overlay when `nudgeAvailable && not nudgeDismissed`
- **Collapsed state**: Icon only, no panel
- **Open state**:
  - Mode selector: 5 chips (Clarify, Strengthen, Challenge, Expand, Synthesise)
  - Turn history: scrollable list of `user` and `assistant` turns
  - Nudge turn: visually distinct from chat turns; "Not relevant" dismiss button
  - `assistant` turns: thumbs down icon on hover (no thumbs up)
  - Chat input: textarea + submit button; disabled while `streamingTurn /= Nothing`
  - Streaming: assistant turn renders progressively as chunks arrive
- **Publish gate modal**: "There's something unresolved here — publish anyway?" with Publish / Go back buttons
- **Consent not granted**: Panel replaced with: "The writing assistant is turned off. [Enable in Privacy & Consent]"
- **CSS classes**: `writing-assistant`, `writing-assistant__icon`, `writing-assistant__dot`, `writing-assistant__panel`, `writing-assistant__modes`, `writing-assistant__mode-chip`, `writing-assistant__turns`, `writing-assistant__turn`, `writing-assistant__turn--user`, `writing-assistant__turn--assistant`, `writing-assistant__turn--nudge`, `writing-assistant__thumbs-down`, `writing-assistant__dismiss`, `writing-assistant__input`, `writing-assistant__submit`

## 13. Operational Metrics

- **Nudge generation rate**: `WritingAssistantNudgeWorker` enqueue and success counts per day
- **Nudge open rate**: ratio of `NudgeReceived` to `OpenAssistantPanel` following a nudge
- **Nudge dismiss rate**: `nudge_dismissed` signal count vs total nudges generated
- **Session depth**: average turn count per session; sessions with >4 turns indicate substantive dialogue
- **Mode distribution**: which modes users select most
- **Feedback rate**: `negative_explicit` signal count per prompt template version
- **Post edit rate after session**: posts updated within 2 hours of a session turn
- **Consent grant rate**: `consent_writing_assistant` true vs false across users
- **Circuit breaker state**: `:writing_assistant_fuse` open/closed transitions

---

## 14. Performance & Usability Metrics

- **Time-to-first-token**: latency from `SubmitChat` to first SSE chunk — target <3s; this is what the user perceives
- **Nudge generation latency**: time from `WritingAssistantNudgeWorker` start to `nudge_generated` event — background, not user-perceived
- **Modal cold start**: if Modal container is cold, first invocation is slower — keep-warm ping sent on session open
- **SSE reconnect rate**: how often the SSE connection drops during an active session

## 15. Cost Tracking

- **Together AI** (`Llama-3.3-70B-Instruct-Turbo`): per-token cost for Socratic dialogue generation. Input: system prompt + post body + retrieved chunks (up to 15, ~6k tokens) + conversation history. Output: single bot turn (~200–400 tokens). Tracked under `writing_assistant` in `mart_cost_tracking`.
- **Together AI** (`Meta-Llama-3-8B-Instruct-Lite`): per-token cost for input classification pre-pass. Cheap; runs on every user message. Tracked under `writing_assistant`.
- **Together AI** (`BAAI/bge-m3`): per-token embedding cost for RAG query. Runs on every turn. Tracked under `writing_assistant`.
- **Together AI** (`Llama-Guard-4-12B`): included as `safety_model` param — no separate charge beyond the inference call.
- **Modal**: per-invocation compute cost for `apps/writing_assistant` service. Tracked under `writing_assistant`.
- **Neon**: pgvector similarity search + FTS hybrid query per turn. Scales with corpus size.
