# US-14.3.1 — Authenticated Navigation State

## 1. User Story

> **As an** authenticated user, **I want** the navigation to reflect my signed-in state **so that** I can confirm I am logged in and see my identity at a glance.

This is automatic. When the user is authenticated, the top navigation updates to show the full set of navigation items and the user's display name in place of "Sign In".

**Acceptance criteria:**
- The navigation shows "Sign In" when unauthenticated and the user's display name when authenticated
- The auth token is included in all API requests to protected endpoints
- Protected pages function correctly when authenticated

---

## 2. UI Interaction Flow

### Happy Path
1. User is authenticated (JWT in localStorage, `model.auth = Just auth`).
2. The navigation bar renders the full authenticated set: Library, Antilibrary, Wish List, Reading Pile, Looking for a Home, Catalogue (with Search and Add Book sub-items), Marketplace, and the user's display name.
3. The display name is clickable, revealing a dropdown with "Settings" and "Sign Out".
4. The active page's nav item has `app-nav__item--active` class.

### Unauthenticated State
1. `model.auth = Nothing`.
2. Navigation shows only: Catalogue, Marketplace, and "Sign In".
3. The brand dropdown always shows "Costs" link.

### Elm State Machine
- **Model fields involved**: `model.auth : Maybe Auth` where `Auth = { user : User, token : AuthToken }`.
- **Rendering logic**: `viewNav` pattern-matches on `model.auth`:
  - `Nothing` -> renders `[Catalogue, MarketplaceBrowse, Login]` nav items
  - `Just auth` -> renders full bookshelf nav, dropdowns for Catalogue/Marketplace/Admin, and `UserMenu.view auth.user model.userMenu`
- **Owner detection**: `isOwner maybeAuth` checks `auth.user.role == "owner"` to conditionally show Admin dropdown.

---

## 3. API Calls

### `GET /api/auth/me`
- **Auth**: Required (Bearer JWT)
- **Pipeline**: `:api`, `:authenticated`
- **Controller**: `StacksWeb.AuthController.me/2`
- **Response**: `{ "user": { "id", "email", "display_name", "role", "profile_visibility", "age_verified", "consent_analytics", "country_code", "city" } }` — HTTP 200
- **Note**: This endpoint is available but not called on page load; auth state is restored from localStorage flags.

---

## 4. Auth & Middleware Guards

- **Session persistence**: Auth data (token, userId, email, displayName, role) is stored in localStorage via the `saveAuth` port and decoded from Elm flags on app init via `decodeFlags`.
- **Token injection**: All authenticated API calls pass the token via `Http.header "Authorization" ("Bearer " ++ token)` in `Api.elm`.
- **Auth pipeline**: `StacksWeb.Plugs.AuthPipeline` verifies Bearer tokens, ensures authentication, loads the user resource, and checks email confirmation.

---

N/A — Navigation state is determined entirely by client-side auth data in localStorage. The `me` endpoint reads from `op.users` but is not called during nav rendering.

## 12. Elm Frontend State Machine (Detail)

### Route
- **Route variant**: N/A — This story affects the global navigation, not a specific route.

### Init
- **App init**: `decodeFlags` parses the Elm flags (injected from localStorage by JS) to extract `Maybe Auth`. Uses `Decode.map5` to decode `token`, `userId`, `email`, `displayName`, `role`.
- **Initial model state**: `model.auth` is `Just { user, token }` if flags contain valid auth data, `Nothing` otherwise.

### Update cycle
- **Auth established**: When `Login.LoggedIn authResponse` OutMsg fires, Main constructs `Auth` and sets `model.auth = Just auth`. Navigation re-renders with authenticated items.
- **Auth cleared**: When `UserMenu.SignOut` OutMsg fires, Main sets `model.auth = Nothing`, calls `clearAuth ()` port. Navigation reverts to unauthenticated items.

### View
- **viewNav rendering**:
  - **Brand section**: Always renders "The Stacks" logo link and "Costs" dropdown item.
  - **Authenticated**: `navItem` for each bookshelf, `navDropdown` for Catalogue (Search + Add Book), Marketplace (Create + My Listings), and conditionally Admin (Sources + Scrapers). UserMenu component renders last.
  - **Unauthenticated**: Simple `navItem` for Catalogue, Marketplace, and Sign In.
  - **Active state**: `navItem` compares `currentRoute == targetRoute` to apply `app-nav__item--active`.
- **ARIA attributes**: `aria-label="Main navigation"` on `<nav>`, `aria-label="User menu"` on user menu container, `aria-expanded` and `aria-haspopup` on user menu trigger button.
- **CSS classes**: `app-header`, `app-header__brand`, `app-nav`, `app-nav__list`, `app-nav__item`, `app-nav__item--active`, `app-nav__link`, `app-nav__dropdown`, `app-nav__dropdown-menu`, `app-nav__dropdown-link`, `user-menu`, `user-menu__trigger`, `user-menu__dropdown`

## 13. Operational Metrics

- **Auth state restoration rate**: Percentage of app loads where valid auth data is successfully decoded from localStorage flags (vs `Nothing`).
- **Stale token detection rate**: Number of times a stored token is present in localStorage but rejected by the API (HTTP 401 on first authenticated request).
- **`/api/auth/me` call rate**: If this endpoint is called, track success (valid token) vs failure (expired/invalid token) rates.
- **Navigation render mode ratio**: Count of authenticated vs unauthenticated navigation renders per session (indicates auth state stability).

---

## 14. Performance & Usability Metrics

- **Auth flag decode time**: Latency for `decodeFlags` to parse localStorage auth data on app init. Should be <5ms (synchronous JSON decode in Elm).
- **Navigation re-render latency**: Time for the navigation bar to update after auth state changes (login or logout). Should be <16ms (single Elm render cycle).
- **User menu interaction rate**: Percentage of sessions where the user opens the display name dropdown.
- **Settings navigation rate**: Percentage of user menu opens that result in a "Settings" click.
- **Sign Out accessibility**: Percentage of logouts initiated via user menu vs other means (e.g., token expiry).

## 15. Cost Tracking

- **Compute**: Zero. Navigation logic runs in the Elm frontend.
