# US-12.3.3 — Model Output Reaches Readers Through Guardrails

## 1. User Story

> **As a** reader, **I want** anything a model wrote to pass safety and sanity checks before I
> see it **so that** the platform's voice stays trustworthy even where it is generated.

**Status: the gap is live and recorded.** Book-post associations ship model output to readers
today with structural validation only (the association must name a real book) — no content
guardrails, and no red-team record for any reader-facing LLM surface.

**Acceptance criteria:**
- Every reader-facing LLM surface is enumerated (associations today; the assistant when it
  ships), each naming its guardrail set and its failure mode (block, flag, degrade).
- A red-team pass is recorded per surface before it ships, and re-run when prompts change.
- Guardrail refusals are observable (US-12.3.2) — a silent filter is an unmeasured one.

## 2. Validation

- Planted adversarial outputs refused per surface; the refusal telemetry asserted.
