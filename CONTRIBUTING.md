# Contributing to The Stacks

Thank you for your interest in The Stacks.

**External contributions are not being accepted at this time.** The project is
in active early development and is maintained by a single developer.

## What you can do

- **Report bugs** — open a [bug report](https://github.com/erinversfeldcodes/thestacks/issues/new?template=bug_report.md)
- **Request features** — open a [feature request](https://github.com/erinversfeldcodes/thestacks/issues/new?template=feature_request.md)
- **Ask questions** — open a [blank issue](https://github.com/erinversfeldcodes/thestacks/issues/new)

## What you cannot do

Pull requests from external contributors will be closed without review. The
source code is publicly visible under a restrictive license — please read
[LICENSE](./LICENSE) before using or referencing this code.

## Code of Conduct

All issue interactions are governed by the [Code of Conduct](./CODE_OF_CONDUCT.md).
